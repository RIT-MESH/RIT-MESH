# ようこそ、リテシュ です 👋

エンタープライズネットワーク、ファイアウォール運用、サーバーインフラ、監視、自動化、AI 支援システムの経験を持つ、インフラ・ネットワーク・クラウド・DevOps エンジニアです。

AWS、Azure、Terraform、Linux、Windows Server、FortiGate、Active Directory、各種監視プラットフォーム、インフラ自動化を活用しています。また、クラウドセキュリティ、インシデントレスポンス、コスト最適化、ディザスタリカバリ、DevSecOps に関する実践的なプロジェクトも構築しています。

## 注目プロジェクト

### [AWS Zero Trust Reference Architecture](https://github.com/RIT-MESH/aws-zero-trust-reference-architecture)

Terraform を用いた本番指向の AWS ゼロトラストアーキテクチャ。マルチ AZ ネットワーク、プライベートワークロード、最小権限 IAM、WAF、KMS 暗号化、集中ログ、自動セキュリティ検証を実装しています。

### [AWS Network Firewall and Security Hub](https://github.com/RIT-MESH/aws-network-firewall-security-hub)
Terraform で構築したセキュアな AWS ネットワークアーキテクチャ。AWS Network Firewall による集中的なトラフィック検査と、AWS Security Hub によるセキュリティポスチャ管理および検出事項の集約を実現しています。

### [Site Reliability Engineering Platform](https://github.com/RIT-MESH/sre-reliability-platform)

監視、インシデントレスポンス、自動化、ディザスタリカバリ、運用検証を網羅する、インフラ信頼性とオブザーバビリティのプロジェクトです。

### [AWS GuardDuty, Tines, and Jira Incident Response](https://github.com/RIT-MESH/aws-guardduty-tines-jira-incident-response)

GuardDuty の検出事項を正規化し、Tines でレスポンスをオーケストレーションし、Jira にインシデントを起票する、自動化されたクラウドセキュリティのインシデントレスポンスワークフローです。Terraform、Python、テスト、CI 検証も含んでいます。

### [AWS Cost Optimization](https://github.com/RIT-MESH/AWS-cost-optimization)

アイドル状態や低利用率のリソースを特定し、推奨を自動化し、可視性を向上させ、実践的な FinOps 管制を適用することに焦点を当てた AWS コスト最適化プロジェクトです。
